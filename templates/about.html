1. Project Overview

The Personalized Health & Fitness Dashboard is a locally hosted web application that empowers users to track daily health habits and receive data-driven feedback. By logging food intake, exercise, and sleep, users gain a clear picture of their health through visualizations, predictive analytics, and personalized recommendations.

2. Objectives

  • Enable users to log daily food intake, exercise sessions, and sleep hours through an intuitive web interface.
  • Calculate and visualize calorie intake vs. calories burned in real time.
  • Predict short-term weight trends using a machine learning regression model.
  • Classify users into health categories using clustering (K‑Means).
  • Provide personalized health recommendations based on user data.

3. Key Features

3.1 User Input

  • Daily food intake with calorie lookup from a web dataset.
  • Exercise type and duration with calorie-burn estimation (MET-based).
  • Sleep hours tracker.

3.2 Dashboard Outputs

  • Calorie intake vs. burn chart (interactive visualizations).
  • Weight trend prediction over time (linear regression).
  • Health cluster category (e.g., Active, Sedentary, Balanced).
  • Personalized recommendation panel (diet, exercise, sleep tips).

5. System Architecture

The application follows a three‑tier architecture: the frontend (Jinja2 + interactive charts) handles user interaction; FastAPI serves as the backend API and orchestrates data processing; SQLite stores user logs and historical data. Machine learning models trained on curated datasets are loaded at runtime to generate predictions and clusters.
