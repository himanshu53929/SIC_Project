What have we build?

We present you, Personalized Health & Fitness Dashboard, which is a locally hosted web application that empowers users to track daily health habits and receive data-driven feedback. By logging food intake, exercise, and sleep, users gain a clear picture of their health through visualizations, predictive analytics, and personalized recommendations.

What you get here?

  • You can track your daily food intake, exercise sessions, and sleep hours through an intuitive web interface.
  • You can view your calorie intake vs. calories burned in real time with good visuals.
  • Your short-term weight trends will be predicted using a machine learning regression model.
  • You can view which category you fall into on the basis of _____.
  • You will get personalized health recommendations.

Key Features

What you need to log?

  • Your daily food intake.
  • Your exercise type and duration.
  • Your sleep sessions.

What we will deliver?

  • Live calorie intake vs. burn chart (interactive visualizations).
  • Weight trend prediction over time (linear regression).
  • Health cluster category (e.g., Active, Sedentary, Balanced).
  • Personalized recommendation panel (diet, exercise, sleep tips).

Hey developers! Want to know what we used?

Backend FastAPI (Python)
Data Processing Pandas
Machine Learning Scikit‑Learn (Regression + K‑Means)
Database SQLite
Visualization Plotly / Chart.js
Frontend Jinja2 templates, HTML/CSS, Bootstrap
Dataset Web datasets for food & exercise calories (USDA FoodData Central)

So, what is our System Architecture?

The application follows a three‑tier architecture: the frontend (Jinja2 + interactive charts) handles user interaction; FastAPI serves as the backend API and orchestrates data processing; SQLite stores user logs and historical data. Machine learning models trained on curated datasets are loaded at runtime to generate predictions and clusters.
